# Redirecciones de la dirección antigua

Esta rama solo existe para que la dirección antigua del sitio
(https://liivne.github.io/cuuna-landing/) lleve a la nueva en Vercel
(https://cuuna.cl). GitHub Pages publica esta rama.

El sitio real está en la rama `main`. No hace falta tocar esta rama al agregar
páginas: `404.html` redirige cualquier dirección antigua que no tenga su propio archivo.
